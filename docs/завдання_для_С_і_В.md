# Завдання діалогам РозкладкаС і РозкладкаВ (31.10.2026)

InTrack 1.69.0 видає доступ до застосунків і приймає підписані знімки.
Підключити спільний пакет `intrack-system/rozkladka_common` (git-залежність)
і:

1. Перший запуск — активація з InTrack замість ручного введення організації:
   екран з кодом телефона → QR-код (або файл `.rza`) → особа, посада й
   підрозділ лише для читання (таблиця `organization` заповнюється з `dept`).
2. «Зберегти знімок для обліку майна» — підписаний `.rzs`.
3. Перенесення на інший телефон — як і раніше, власним знімком; на новому
   телефоні — нова активація.
4. Схему бази не змінювати без InTrack (`docs/modules/app-exchange.md`).

Непідписані `.db` від РозкладкаС і РозкладкаВ InTrack поки приймає — на час
переходу. Протокол — `docs/протокол_активації.md`.
