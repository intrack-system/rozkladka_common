# rozkladka_common — передача в роботу

Створено 31.10.2026 порожнім. InTrack 1.69.0 уже видає QR-коди активації й
приймає підписані знімки `.rzs`; застосунки цього ще не вміють.

## Що зробити (діалог застосунків)

1. Flutter-пакет (`lib/`, тести дзеркалять `lib/`, `flutter_lints`).
2. Ключ телефона ECDSA P-256 у захищеному сховищі, без експорту, з вимогою
   відбитка/PIN телефона на підписання: власний код для Android (Kotlin,
   Keystore, `setUserAuthenticationRequired`) і iPhone (Swift, Secure
   Enclave) через MethodChannel.
3. Код телефона з відкритого ключа (SPKI DER) — алгоритм у протоколі;
   екран «Застосунок не активовано» з кодом великими літерами.
4. Сканування QR-коду (`mobile_scanner`) і відкриття файлу `.rza`;
   перевірка ES256 відкритим ключем InTrack (вшивається у збірку),
   `app`, `dev` = власний код, `scan_before`. Збереження `aid`, `sub`,
   `dept`; особа й підрозділ — лише для читання.
5. «Зберегти знімок» → `.rzs`: ECDH P-256 з відкритим ключем InTrack →
   HKDF-SHA256 → AES-256-GCM, підписаний заголовок, лічильник `n`
   зберігається в застосунку й лише зростає.
6. Тести на `docs/тестові_вектори.json`: код телефона, перевірка
   `activation_token`, розшифрування `snapshot_rzs_b64` тестовим ключем
   InTrack дає `snapshot_plain_b64`; власний `.rzs` розшифровує еталон.
7. Підключити в РозкладкаС, Е, Д; РозкладкаВ — через її діалог.
