# Передача майна між телефонами — RZ2

Один формат для всіх Розкладок (`lib/src/qr_pack.dart`, екрани — `lib/src/screens/pack_screens.dart`).
Замінив RZT1/RZP1/RZC1 (JSON + base64, серія RZQ1). RZQ1 лишився лише для довгого QR-коду активації.

## Порядок

1. Приймач показує **код приймача** (~260 знаків, версія 8): застосунок, номер особи за списком
   особового складу, прізвище, ключ телефона, разовий ключ — підписано ключем телефона.
2. Передавач сканує його, вносить підставу (рапорт, наказ, акт) і показує **сторінку кодів**:
   картка на кожен код з переліком одиниць, знизу — підстава, «Надіслати файлом», «Підтвердження».
3. Приймач сканує коди в будь-якому порядку (камера, фото, файл `.rzt`), бачить перелік, приймає.
4. Приймач показує **код підтвердження** (версія 4); передавач сканує — передачу завершено.

## Код

Текст `RZ2:` + base45 (RFC 9285) двійкових даних — QR-код у буквено-цифровому режимі.
Числа — змінної довжини (7 біт у байті), ключі P-256 — стиснені (33 байти), підпис ES256 r‖s (64).

| Вид | Байти |
|---|---|
| Приймач `I` | 0x49, застосунок (0 В, 1 С, 2 Е, 3 Д), особа, довжина + прізвище UTF-8, ключ телефона 33, разовий ключ 33, підпис 64 |
| Частина пакета `T` | 0x54, застосунок передавача, номер пакета 6, № частини, усього частин, ключ телефона передавача 33, разовий ключ передавача 33, iv 12, шифротекст, тег 16, підпис 64 |
| Підтвердження `C` | 0x43, номер пакета 6, підпис 64 над (0x43 ‖ номер ‖ SHA-256 кодів пакета, рядками) |

Шифрування частини: ECDH(разовий передавача, разовий приймача) → HKDF-SHA256 (сіль `RZ2`, info — разовий
ключ приймача) → AES-256-GCM, AAD — усе до шифротексту. Вміст — raw deflate тексту: у частині 0 перший
рядок — шапка JSON `[від, прізвище, кому, прізвище, підстава, дані застосунку]`, далі рядки одиниць у
форматі застосунку (без переносів).

Пакет ділиться за рядками: у код — скільки влазить у версію 30 (1680 байт), кожен код окремо
зашифровано й підписано. Рядок, що не влазить навіть у версію 40, — лише файлом.

## Особа

Номер особи — зі списку в QR-коді активації. Передавач показує прізвище за своїм списком; ключ
телефона прив'язує особу лише в обліку майна (знімки), на місці — телефони поруч.
